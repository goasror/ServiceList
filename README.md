# TShTMDM DM — прейскурант цен / narxlar ro'yxati

Статический сайт-калькулятор медицинских услуг. Пациент или регистратор
отмечает нужные услуги, видит итоговую сумму и печатает результат в PDF.

Без сервера, без базы данных, без сборки — только HTML, CSS и один файл JavaScript.

Интерфейс на двух языках: русский (по умолчанию) и узбекский, переключатель RU/UZ
в шапке. Выбранный язык запоминается в браузере.

## Как менять цены (программирование не нужно)

Все услуги лежат в **`services.js`**. Отредактируйте этот файл прямо на GitHub —
сайт обновится сам в течение минуты.

1. Откройте `services.js` на GitHub.
2. Нажмите на карандаш (Edit this file).
3. Измените, добавьте или удалите строки **ниже шапки с комментарием**.
4. Нажмите **Commit changes**.

Файл начинается блоком комментария и строкой `window.SERVICES_CSV = String.raw``,
а заканчивается строкой ``;`. Эти строки трогать нельзя — всё, что между ними,
обычная таблица.

### Формат строки

Шесть колонок через запятую, в этом порядке:

```
category_ru,category_uz,name_ru,name_uz,price,active
Функциональные исследования,Funksional tekshiruvlar,Электроэнцефалография (ЭЭГ),Elektroensefalografiya (EEG),90000,1
```

| Колонка | Что это |
|---|---|
| `category_ru` | Название раздела по-русски. **Это ключ раздела** — строки с одинаковым `category_ru` группируются вместе. Порядок разделов = порядок первого появления в файле. |
| `category_uz` | То же название по-узбекски (показывается при UZ). |
| `name_ru` | Название услуги по-русски. |
| `name_uz` | Название услуги по-узбекски. |
| `price` | Только цифры, без пробелов и без «сум». Пишите `90000`, а не `90 000`. |
| `active` | `1` — услуга показывается, `0` — скрыта. Можно оставить пустым (= показывается). |

**Запятые в названии.** Возьмите всё название в двойные кавычки:

```
Ультразвуковая диагностика,Ultratovush diagnostikasi,"УЗИ печени, желчного пузыря","Jigar, o't pufagi UTT",75000,1
```

Кавычки внутри названия — удвоить.

**Единственный запрещённый символ — обратная кавычка (`).** Она закрывает блок
данных и ломает страницу. В медицинских названиях её не бывает; апострофы
в узбекских словах (o'pka, bo'g'im) — это обычный прямой апостроф, он безопасен.

Строка с неверной ценой или без названия пропускается, а сообщение выводится
в консоль браузера — остальной список продолжает работать.

### Как временно убрать услугу

Поставьте `0` в колонке `active`. Строка останется в файле вместе с ценой
и переводом, но на сайте её не будет. Вернуть — поставить `1`.

## Шапка и подписи

`config.js` содержит название клиники, дату «Обновлено», валюту, сноску под
итогом и все подписи интерфейса на обоих языках. Внутри — обычный JSON.

```js
window.APP_CONFIG = {
  "clinicName": "TShTMDM DM",
  "updatedDate": "17.07.2026",
  "defaultLang": "ru"
};
```

`updatedDate` не проставляется автоматически — меняйте её вместе с ценами.

## Как посмотреть локально

Просто откройте `index.html` двойным щелчком. Ничего устанавливать и запускать
не нужно: ни Node, ни Python, ни сборки, ни локального сервера. Данные лежат
в обычных script-файлах, поэтому страница одинаково работает и по `file://`,
и на любом хостинге.

## Публикация

**GitHub Pages** — запушьте в `main`. Workflow `.github/workflows/pages.yml`
публикует репозиторий как есть. Один раз включите в
*Settings → Pages → Source: GitHub Actions*.

**Netlify** — подключите репозиторий. `netlify.toml` уже указывает корень
репозитория как папку публикации, без команды сборки.

## Как работает PDF

Кнопка «Скачать» открывает диалог печати браузера, где пользователь выбирает
**Сохранить как PDF**. Стили печати скрывают весь интерфейс, кроме бланка
расчёта — то, что видно в предпросмотре, и попадает в PDF.

## Файлы

| Файл | Что это |
|---|---|
| `services.js` | Прейскурант. Единственный файл, который нужно трогать большинству. |
| `config.js` | Название, дата, подписи интерфейса на RU/UZ. |
| `index.html` | Структура страницы. |
| `styles.css` | Все стили, включая печать. |
| `app.js` | Разбор таблицы, поиск, фильтры, выбор, итог, печать. |

Зависимостей нет. Ни `package.json`, ни `node_modules`, ни сборки.

## Примечания

- Выбранные услуги хранятся в `sessionStorage`: переживают перезагрузку страницы
  и стираются при закрытии вкладки. Никуда не отправляются и на сервере не хранятся.
- Поиск работает по обоим языкам одновременно: `гепатит` и `gepatit` найдут одни
  и те же строки независимо от текущего языка интерфейса.
- Данные внутри `services.js` хранятся в формате CSV. Если понадобится Excel —
  скопируйте всё между обратными кавычками и сохраните как `.csv`.
- Услуги, зачёркнутые ручкой в бумажном прейскуранте от 17.07.2026, перенесены
  в CSV с `active=0`. Проверьте их и верните `1`, если они всё же оказываются.
